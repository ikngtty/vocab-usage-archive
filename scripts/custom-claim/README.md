# Vocab Usage Archive - Scripts - Custom Claim

A script to manage custom claims.

## Preparation

```shell
$ npm install
```

```shell
$ gcloud auth application-default login
```

## Run

```shell
$ node index.js show [email]
```

```shell
$ node index.js add [email] [claim]
```

```shell
$ node index.js remove [email] [claim]
```

```shell
$ node index.js delete [email]
```
